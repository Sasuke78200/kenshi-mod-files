# Kenshi .mod Format Documentation

A reverse-engineering project focused on documenting Kenshi `.mod` files and building tooling around the format.

The initial objective is translation support: extract translatable data from `.mod` files into a format that can be edited easily, then import the translated content back into the original mod structure.

Planned features include JSON export/import, structured parsing, translation extraction, and public documentation of the binary format.

## License / Disclaimer

This documentation is the result of reverse engineering and may contain mistakes.

It is intended for interoperability, modding, documentation, and translation tooling.
